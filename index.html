Walkthrough

Step-by-Step Implementation

01
DNS Configuration on Client
The Windows 10 VM was using the home router's DNS by default, which couldn't resolve mylab.local. Fixed by pointing DNS to the Domain Controller.
POWERSHELL — ADMIN
# Set DNS to Domain Controller
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses ("192.168.1.200")
Clear-DnsClientCache
nslookup mylab.local 192.168.1.200
✓ RESULT
Server: winserver2022.homelab.local
Address: 192.168.1.200
Name: mylab.local → 192.168.1.200
02
Domain Join
Joined the Windows 10 Pro VM to the mylab.local Active Directory domain using PowerShell. The machine restarted automatically after joining.
POWERSHELL — ADMIN
Add-Computer -DomainName "mylab.local" -Credential mylab.local\Administrator -Restart

# Verify after restart
systeminfo | findstr /B /C:"Domain"
✓ RESULT
Domain: mylab.local
03
Domain User Creation
Created a domain user account in Active Directory from the Domain Controller using PowerShell.
POWERSHELL — WINSERVER2022
New-ADUser -Name "Neil Marvin Simon" `
  -GivenName "Neil Marvin" `
  -Surname "Simon" `
  -SamAccountName "nsimon" `
  -UserPrincipalName "nsimon@mylab.local" `
  -AccountPassword (ConvertTo-SecureString "Welcome123!" -AsPlainText -Force) `
  -Enabled $true `
  -Path "CN=Users,DC=mylab,DC=local"
✓ USER CREATED
Name: Neil Marvin Simon | Account: nsimon | UPN: nsimon@mylab.local | Enabled: True
04
RDP Configuration
Enabled Remote Desktop on the Windows 10 client, configured Windows Firewall rules, and added the domain user to the Remote Desktop Users group.
POWERSHELL — WIN10 ADMIN
# Enable RDP
Set-ItemProperty -Path 'HKLM:\System\CurrentControlSet\Control\Terminal Server' `
  -Name "fDenyTSConnections" -Value 0

# Open Firewall
Enable-NetFirewallRule -DisplayName "Remote Desktop*"
Set-NetFirewallRule -DisplayName "Remote Desktop*" -Profile Any -Enabled True

# Add domain user
Add-LocalGroupMember -Group "Remote Desktop Users" -Member "mylab\nsimon"

# Enable ping
Enable-NetFirewallRule -DisplayName "File and Printer Sharing (Echo Request - ICMPv4-In)"
✓ RDP METHODS
mstsc /v:192.168.1.10
mstsc /v:CPC-NSimon-001
mstsc /v:CPC-NSimon-001.mylab.local
05
Computer Rename via PowerShell
Renamed the Windows 10 client from the default name DESKTOP-750KQC6 to a professional naming convention CPC-NSimon-001. Active Directory synced automatically after restart.
POWERSHELL — WIN10 ADMIN
Rename-Computer -NewName "CPC-NSimon-001" `
  -DomainCredential mylab\Administrator -Restart

# Verify in AD from WinServer2022
Get-ADComputer -Filter * | Select-Object Name, DNSHostName
✓ COMPUTERS IN AD
WIN-6ARV79FMB48 → WIN-6ARV79FMB48.mylab.local (DC)
CPC-NSimon-001 → CPC-NSimon-001.mylab.local (Client)

Troubleshooting

Issues Encountered & Fixes

DNS_PROBE — mylab.local not found
CAUSE
Client was using home router DNS (IPv6) instead of the Domain Controller's DNS server.
✓ FIX
Manually set DNS to 192.168.1.200 using Set-DnsClientServerAddress and flushed cache.
Domain Join — Access Denied
CAUSE
Wrong credential format used (mylab\ instead of mylab.local\) and DNS not yet configured.
✓ FIX
Fixed DNS first, then used full domain format mylab.local\Administrator with correct password.
Ping Timeout from Server to Client
CAUSE
Windows 10 Firewall blocks ICMP (ping) requests by default.
✓ FIX
Enabled the ICMPv4 Echo Request rule via Enable-NetFirewallRule.
Remote Rename — RPC Unavailable
CAUSE
WinRM not configured on the client, blocking remote PowerShell commands from the server.
✓ FIX
Ran the Rename-Computer command directly on the Windows 10 VM instead of remotely.
